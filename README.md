# Credit Card Rewards

A modern, high-performance web application designed to help users manage their credit card rewards and discover the best cards for their spending patterns. Built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/), the app features a sleek, premium design inspired by the NeoPop aesthetic.

## 🚀 Features

-   **Card Stack Management**: Visually manage multiple credit cards with a beautiful interactive stack.
-   **Rewards Analysis**: Tracking and visualization of rewards for different spending categories.
-   **Advanced Search**: Quickly search through cards and reward types.
-   **NeoPop UI Components**: Custom-built, high-quality UI elements for a unique and responsive user experience.
-   **Add Card Flow**: Intuitive modal-based flow for adding new cards with color pickers and network selection.

## 🛠 Tech Stack

-   **Framework**: [Next.js 15 (App Router)](https://nextjs.org/docs)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Icons/Images**: Custom NeoPop assets and SVG icons.

## 🏁 Getting Started

### Prerequisites

-   Node.js 18.x or later
-   npm or pnpm

### Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/karthiikJR/credit-card-rewards.git
    cd credit-card-rewards
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Run the development server:
    ```bash
    npm run dev
    ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

-   `app/`: Contains the main application pages, layouts, and components.
    -   `components/`: Reusable React components.
        -   `custom/`: Core NeoPop UI primitive components.
    -   `data/`: Mock data or configuration for cards and rewards.
    -   `lib/`: Utility functions and shared helpers.
    -   `types/`: TypeScript interface and type definitions.
-   `public/`: Static assets such as images and SVGs.
